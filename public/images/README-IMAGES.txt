MUNNASAH MCC WEBSITE - IMAGE REPLACEMENT GUIDE
==============================================

You can replace any image in this folder with your own MCC photo.
IMPORTANT: Keep the SAME filename and file extension (.jpg).
You do NOT need to edit React code if you keep the filename unchanged.

HOW TO REPLACE AN IMAGE
-----------------------
Example: To change the homepage photo:
1. Choose your MCC project photo.
2. Rename it to: hero.jpg
3. Copy it into: public/images/
4. When Windows asks to replace the file, choose Replace.
5. Refresh the website.

RECOMMENDED IMAGE SIZE
----------------------
Hero:     1920 x 1080 or larger
Projects: 1400 x 900 or larger
Gallery:  1200 x 800 or larger
Team:     1400 x 1000 or larger

Use landscape JPG images for the best result.
